# DistantWynn

Dynamically adjust the visible region based on the player's location in Wynncraft.

![demo](./demo.png)

## Features

- List of predefined regions:
  - Wynn (main region)
  - Realm of Light
- Voxy support:
  - Automatic region detection outside the predefined list
